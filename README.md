# ⚔️ suwupnil.github.io — Minecraft Pixel Portfolio

> Minimal, striking, Minecraft-inspired pixelated developer portfolio for **Swapnil** ([@suwupnil](https://github.com/suwupnil)).  
> Live at [**pnil.me**](https://pnil.me).

---

## ✨ Features

- 🌿 **Biome Switcher**: Real-time theme shifting across **Overworld**, **Nether**, and **The End** palettes with adaptive floating pixel motes.
- 🎒 **Chest Inventory**: 12-slot Minecraft chest showcasing open-source projects with item rarity tiers, stat buffs, and hover lore tooltips.
- ⚒️ **Crafting Inspector**: Click any item to inspect its recipe, enchantment stack, and launch live demos or GitHub source.
- ⚗️ **Code Alchemy & Enchanting Table**: Visualized language proficiencies (Swift, Rust, JavaScript, Python, etc.) with custom Minecraft XP tracks and enchantment names.
- 🎮 **9-Slot Interactive Hotbar**: Persistent HUD with slot keyboard shortcuts (`1` through `9`), heart health indicators, and dynamic XP bar.
- 💬 **Minecraft Command Console**: Press `/` anywhere to open the chat console. Supports `/help`, `/stats`, `/tp`, `/theme`, `/projects`, and `/ping`.
- 🧭 **F3 Debug Screen**: Authentic F3 coordinates, player metadata, and rapid contact portals.
- 🔊 **8-Bit Audio Synthesizer**: Pure Web Audio API synthesized retro sound effects (XP chimes, wooden clicks, level-up fanfare) with mute toggle.
- 🏆 **Advancement Toasts**: Minecraft achievement popups celebrating milestones.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Typography**: Press Start 2P, Silkscreen, VT323
- **Audio**: Web Audio API (zero external sound files)
- **Deployment**: GitHub Pages via GitHub Actions CI/CD ([pnil.me](https://pnil.me))

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
